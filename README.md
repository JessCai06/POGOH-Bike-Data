## What this Project is about

**What is it?** A browser-based dashboard that shows dock occupancy over time for every POGOH station in Pittsburgh: rentable fit (normal) bikes, rentable efit (electric) bikes, and unrentable bikes awaiting operator pickup, with a running mean and operator-trip overlays. It is built to help dispatchers see where bikes are piling up or running short, and to inform dock sizing decisions.

**My Acknowledgements** My thanks to Johnathan Morris and the [POGOH team](https://pogoh.com/) for this opportunity!

**Funding** Funded by the first cohort of Dietrich College Summer Community Engagement Grant (May - August 2026).

## Repo structure

| Path | Contents |
| --- | --- |
| `index.html` | The occupancy dashboard (single-file, no build step). Loads data from `Condensed Occupancy Data/`. |
| `graph.html` | Secondary graph view. |
| `Condensed Occupancy Data/` | Per-station occupancy CSVs, plus `manifest.json`, `station_names.json`, `operator_trips.json`, and hourly/weekday occupancy averages. Generated by `occupancy_averages_per_station.py`. |
| `Scraper/` | The station-status scraper that polls POGOH's public feed every 5 minutes and backs up changes daily. See [Scraper/readme.md](Scraper/readme.md). |
| `Dock Sizing/` | Flow-rate analysis and visualization (`flow_rate_data_cleaning.py`, `flow_rate_viz.py`, `flow_rate_viz.html`) used to evaluate dock capacity. |
| `Open Source Scraped Data/` | Station location data scraped from public sources. |
| `assets/` | Hero image, demo GIFs, and design mockups used in this README. |

Raw data (`Station Sample Data/`, `Occupancy Data/`) is git-ignored.

## Running locally

Browsers block `fetch` on `file://` URLs, so serve the folder over HTTP:

```
python -m http.server 8000
```

Then open <http://localhost:8000/>.
